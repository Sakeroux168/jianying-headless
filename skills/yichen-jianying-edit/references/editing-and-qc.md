# 剪辑判断与音频质检

## 删留

- DELETE：同一信息的重说、没有完成的半句、明显口误、独立犹豫音、无信息量的连续前缀。
- KEEP：支撑论点的演示、承接、限定语，以及听起来短但语义必要的词。
- CHECK：删掉会改变结论、数字口径不明、接句后可能断意、声音边界拿不准。向用户展示具体
  位置与影响，不能只问「这段删吗」。

先完成句段层面的取舍，再清气口。不要为了短删掉正常限定词，造成「比较高性价比」只剩后半
个音节。选中的删除区间与被保护的有效发音不能重叠。

## 切口

ASR 对短词的起止会偏几十到几百毫秒。给每个保留词留必要的发音边界，但不要把相邻已删词的
起音留回来。RMS 低能量点只帮助选切点，不要把「低于某 dB」直接当成呼吸标签。

必要时记录时间戳修正：原时间、修正时间、相关词、波形/试听或复转写证据。保留完整的「好」，
去掉后面废句的「它」；去掉「嗯」的尾音，同时保护接下来的「我」。

长句跨多个视频物理片段时，字幕按保留的语义短句组织，不要求一段视频对应一条字幕。单屏尽量
一至两行；英文产品名占不同宽度，需要画面检查。字幕避开脸、界面按钮和重要数据。

## 本机转写（Windows / FunASR）

- 环境：`E:\Dev\asr-venv`，用 `E:\Dev\asr-venv\Scripts\python.exe`；模型缓存在
  `E:\Dev\modelscope-cache`（离线时设 `MODELSCOPE_CACHE`，或直接传本地模型目录）。
- 模型：`paraformer-zh`，标点用 `ct-punc-c`（小的那个）。**大的 `ct-punc` 在 Windows 上
  加载会报错**，不要换回去。
- 必须取**逐字时间戳**：FunASR 返回的 `timestamp` 是与 `text` 逐字对应的
  `[[start_ms, end_ms], ...]`。不要用 `sentence_timestamp=True` 的整句结果，句子边界和字
  的时间对不上，切点会飘。
- 汇总成 JSON 交给 `edit_plan.py`：`{"text": "全文", "words": [{"w": "字", "start": 秒,
  "end": 秒}, ...]}`，`protect` 区间按下面的修正规则填。转写脚本写进本次 `work\` 目录，
  不写进仓库；同一份素材只转一次，结果按内容哈希复用。

## 切点按音量修正

ASR 给的字起止时间普遍偏 40–80 毫秒（起点偏晚、终点偏早，偶尔反过来）。不要直接用 ASR
时间下刀，按波形修正：

1. 先转成单声道 PCM 复查：`ffmpeg -i 输入.mp4 -vn -ac 1 -ar 48000 -c:a pcm_s16le -y WORK\audio.wav`。
2. 切入：从 ASR 起点**往前**找最近的、连续 40 毫秒 RMS 都低于 -45 dBFS 的窗口，
   把切点定在该窗口起点。
3. 切出：从 ASR 终点**往后**找同样的窗口，把切点定在该窗口终点。
4. 40 毫秒 @ 48 kHz 就是 1920 个采样点；窗口里每个点都要低于 -45 dBFS 才算，不能只看均值。
5. 找到的位置替换 `edit_plan.py` 计划里的 `keeps[].start/end` 和 `protect`；`protect` 仍要
   包住完整发音，不能因为往前找了低能量点就把保护词切掉。

已知观感问题：第一版按这个规则把停顿收到 0.03–0.22 秒，有些接缝听起来略卡。可以少收一点
（留 0.15–0.3 秒），或在接缝加叠化（白名单里）。

## 复查顺序

1. 全片源稿：重复、残句、逻辑跳跃与 CHECK 项。
2. 首版剪后 WAV：完整复转写一次，核对信息是否保留、是否残留重说或长空白。
3. 有具体问题才改对应边界并检查短窗口；新版文件用新 hash，不覆盖旧文件后误用旧缓存。
4. 剪映最终草稿：原生播放、保存、冷启动、现场结构回读。

`render-audio` 用与草稿相同的保留区间、速度和目标长度，只导出音频，不生成视频。ffmpeg 的
变速实现与剪映可能不同，它证明的是文字/时间映射和候选剪口，不能替代剪映里的真实听感。

静音检测只列候选，建议关注超过 180–250 ms 的间隔，阈值随素材调整。词内停顿、英文拼读的
间隔不应机械删除。没有静音段不等于没有呼吸声；没有解码错误也不等于剪辑质量通过。

ASR 拼错 Aisa、Vibe Coding、Skill、Similarweb、GEO、KOL 等名称时，用画面和上下文校正
字幕，保留原声。识别器偶发重复和真正重口要区分，不要为了让转写文本「完美」无休止重跑。

## 停止条件

没有未解决的明确语义或剪口问题、字幕映射完整、原生草稿通过保存和冷启动，即可交付。只有新
改动、新失败或明确未解疑点才增加检查。不能声称已经人耳全片试听、没有任何气口或完成导出，
除非本次确有相应证据。

最终交付强调草稿状态；转写记录、SRT 与删留方案按任务需要保留，不为质检默认生成 MP4。
